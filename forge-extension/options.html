Setup Instructions

The companion is a small Node.js script that runs locally and receives prospects from this extension, writing them directly into your forge-workspace/prospects/ folder.

One-time setup: Open a terminal and run:

node /path/to/forge-extension/forge-companion.js

The first run will ask for your workspace path and save it to ~/.forge-companion.json. After that, just run the same command whenever you want to capture prospects.

Tip: Add an alias to your shell profile so you can start it with forge from anywhere.
